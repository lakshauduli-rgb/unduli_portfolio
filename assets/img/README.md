# Image assets

Drop your real photos into this folder using the **exact filenames** below —
the site already links to them, so nothing else needs to change once the
files exist here.

| Filename                 | Used for                              | Suggested size |
|---------------------------|----------------------------------------|-----------------|
| `profile-photo.jpg`       | About section headshot                 | 800 × 1000 px (portrait) |
| `project-glider.jpg`      | Glider Aerodynamic Design card         | 1200 × 750 px |
| `project-falconee.jpg`    | Falcon E Racing card                   | 1200 × 750 px |
| `project-smartcook.jpg`   | Smart Cooking System card              | 1200 × 750 px |
| `project-scooter.jpg`     | Kick Scooter Manufacturing card        | 1200 × 750 px |
| `project-mixer.jpg`       | Reverse Engineering — Hand Mixer card  | 1200 × 750 px |

Until a file exists, the site automatically shows a labelled placeholder
in its place, so the layout won't break — just add photos whenever you
have them.

Tips:
- Keep photos under ~500 KB each (export at 80% JPEG quality) so the site
  loads fast on GitHub Pages.
- Landscape (16:10) shots work best for project cards; portrait for the
  profile photo.
